To understand the structure of a vector space, we need to know what creates it (Spanning) and what is redundant (Dependence).

## Core Concepts

1.  **Linear Combination**: Creating new vectors by scaling and adding existing ones ($c_1v_1 + ... + c_kv_k$).
2.  **Linear Independence**: No vector in the set can be written as a linear combination of the others.
3.  **Spanning Set**: The set of all possible linear combinations.

<Concept title="The Basis">
  A **Basis** is the "Goldilocks" set of a vector space. It is:
  1.  Large enough to <MarkerHighlight color="green">Span</MarkerHighlight> the space.
  2.  Small enough to be <MarkerHighlight color="blue">Linearly Independent</MarkerHighlight>.
</Concept>

## Dimension

The <StrokeUnderline variant="double" color="#ec4899">dimension</StrokeUnderline> of a vector space is simply the **number of vectors in its basis**. This number is unique for a given space.
