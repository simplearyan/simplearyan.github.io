## How It Works

The component monitors your site's theme state. When you switch modes, it automatically:
1.  Detects the change.
2.  Updates the SVG text colors.
3.  Adjusts the background (if using the "colorful" variant).

```jsx
// It just works!
<Markmap markdown="# My Map..." />
```
