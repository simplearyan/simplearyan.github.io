# Visual Anchors Plan

The concepts presented across the chapters of the "Stats 2 book" lend themselves well to concrete visual illustrations. We are moving beyond static images to interactive Astro components.

## 1. Basic Probability (Chapter 1)

**Goal:** define fundamental vocabulary (Sample Space, Outcome, Event).

| Anchor | Concept | Implementation |
| :--- | :--- | :--- |
| <Dice value={5} size={40} color="#eee" /> | **Sample Space ($S$)** | Use 3D dice to show $S=\{1..6\}$. |
| <Coin outcome="heads" size={40} color="gold" /> | **Binary Outcomes** | Flipping coins for $P(H)=0.5$. |

## 2. Sampling & Repeated Trials (Chapter 2)

**Goal:** Emphasize repetition and replacement.

| Anchor | Concept | Implementation |
| :--- | :--- | :--- |
| **Repetitive Flips** | **Bernoulli Trials** | Sequences of <Coin size={30} /> to show Binomial/Geometric patterns. |
| <Urn size={60} ballCounts={{red:3, blue:5}} /> | **Sampling Dependence** | Urn schemes for Hypergeometric distribution (Sampling without replacement). |

## 3. Discrete Random Variables (Chapter 3)

**Goal:** Shift from concrete outcomes to numerical functions.

*   **Multi-Flip Coin Table**: Mapping outcomes ($hhh \to 3$) using tables.
*   **Convolution**: Using multiple dice <Dice size={30} /> + <Dice size={30} /> to explain summing random variables.
