We can now render beautiful, **hand-drawn vector diagrams** directly in Markdown. No more screenshots! These graphs are generated by our `EquationGraph` component, which means they are crisp, scalable, and theme-aware.

Here is the standard Cartesian plane with our basis vectors $\hat{i}$ and $\hat{j}$.

<EquationGraph
  title="Figure 1.2: Vector visualization on R2"
  variant="paper"
  domain={[-2, 2]}
  range={[-2, 2]}
  grid={true}
  height={400}
  width={400}
  vectors={[
    { start: [0, 0], end: [1, 0], color: "red", label: "î", width: 3 },
    { start: [0, 0], end: [0, 1], color: "red", label: "ĵ", width: 3 },
    { start: [0, 0], end: [1, 2], color: "blue", label: "(1, 2)", width: 2 },
    { start: [0, 0], end: [-1, -1], color: "blue", label: "(-1, -1)", width: 2 }
  ]}
/>

<Callout type="note" title="Implementation Details">
  This graph uses the `paper` variant to simulate a notebook look. Notice the "ink" styling on the arrows!
</Callout>

<ColoredHeading level={2} text="2. Vector Addition" color="#ef4444" style="highlight" />

We can also demonstrate the **Parallelogram Law** of vector addition dynamically.

If we want to add vectors $(1, 2)$ and $(2, 1)$, we complete the parallelogram. The resulting vector $(3, 3)$ is the diagonal.

<EquationGraph
  title="Figure 1.4: Visualization of vector addition in R2"
  variant="paper"
  domain={[-1, 4]}
  range={[-1, 4]}
  grid={true}
  height={400}
  width={400}
  vectors={[
    { start: [0, 0], end: [1, 2], color: "blue", label: "(1, 2)", width: 2 },
    { start: [0, 0], end: [2, 1], color: "blue", label: "(2, 1)", width: 2 },
    
    // Parallelogram completion (dashed)
    { start: [1, 2], end: [3, 3], color: "blue", dashed: true, width: 1 },
    { start: [2, 1], end: [3, 3], color: "blue", dashed: true, width: 1 },
    
    // Resultant
    { start: [0, 0], end: [3, 3], color: "red", label: "(3, 3)", width: 3 }
  ]}
/>

<ColoredHeading level={2} text="3. Headings with Personality" color="#8b5cf6" style="bracket" />

You might have noticed the headings on this page are different. They use our new `<ColoredHeading />` component!

We can choose different styles to match the tone of the section:

*   **Gradient**: For main topics.
*   **Highlight**: For important concepts.
*   **Bracket**: For technical notes or asides.
*   **Underline**: For classic sections.

This allows us to create a **visual hierarchy** that guides the reader's eye, making learning more effective and enjoyable.
